| D-049 | 2026-11-16 | Agent 1 extraction rules, first part (`src/multi_agentic_security/agents/agent1_ingestion/`, stage version `agent1/0.1`). (f) **JSON line numbers**: `json` gives none, so JSON records have `source_line = null` and a JSON pointer in their reasons; identifiers use the pointer and occurrence, so they stay stable and unique. (g) **Intake**: ZIP archives and folders are read in memory only; nothing is extracted to disk or executed. Absolute paths, drive letters, `..` segments, NUL characters, duplicate paths (case-insensitive, trailing dots and spaces ignored) and limit breaches on entry count (read from the end-of-central-directory record before the ZIP index is parsed), total size, upload size or depth reject the whole upload; symbolic links, junctions, hard links, files replaced between check and read, encrypted entries, special files, oversized files and entries above a compression ratio of 200 are skipped and reported; only files Agent 1 parses are read; `node_modules`, `.git`, virtual environments and similar folders are skipped and reported; nested archives are reported, not opened.
